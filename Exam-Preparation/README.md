## Exam Format Reminders

| Format              | Tips                                          |
| ------------------- | --------------------------------------------- |
| **Single Choice**   | Eliminate 2 obviously wrong answers first     |
| **Multiple Choice** | "Select ALL that apply" - usually 2-3 correct |
| **Drag & Drop**     | Order matters; use provided scratchpad        |
| **Hot Area**        | Click correct code section/diagram part       |
| **Case Study**      | Read questions FIRST, then case study         |

**Time:** ~150 minutes | **Questions:** ~40-60 | **Passing:** 700/1000

## Quick Command Reference

```bash
# Build SQL Project
dotnet build DatabaseProject.sqlproj --configuration Release

# Deploy DACPAC
sqlpackage /Action:Publish /SourceFile:bin/Release/DatabaseProject.dacpac /TargetConnectionString:"..." /p:DropObjectsNotInSource=False

# Generate Deploy Script
sqlpackage /Action:Script /SourceFile:DatabaseProject.dacpac /TargetConnectionString:"..." /OutputPath:deploy.sql

# Drift Report
sqlpackage /Action:DeployReport /SourceFile:DatabaseProject.dacpac /TargetConnectionString:"..." /OutputPath:drift.xml

# Run tSQLt Tests
sqlcmd -S "(localdb)\MSSQLLocalDB" -d TestDB -Q "EXEC tSQLt.RunAll;"
```
